ESP32 WiFi/Bluetooth

Prix : 9 000 FCFA

Module ESP32 WiFi/Bluetooth

Le ESP32 est un microcontrôleur puissant et polyvalent intégrant le WiFi et le Bluetooth. Idéal pour les projets IoT, domotiques, de robotique et d’acquisition de données.

Caractéristiques principales :

  • Microcontrôleur dual-core Xtensa LX6 cadencé jusqu’à 240 MHz
  • Mémoire : jusqu’à 520 Ko de SRAM + mémoire flash externe
  • Connectivité : WiFi 802.11 b/g/n et Bluetooth v4.2 BLE
  • Nombre de GPIO : environ 34 E/S programmables
  • Interfaces : UART, SPI, I2C, PWM, ADC, DAC, CAN, etc.
  • Tension : 3,0 V à 3,6 V
  • Programmable avec Arduino IDE, PlatformIO, MicroPython, etc.

Avantages :

  • Connexion sans fil intégrée
  • Puissance de calcul élevée
  • Grande flexibilité
  • Idéal pour l’IoT

Limitations :

  • Consommation électrique plus élevée qu’un Arduino UNO/Nano
  • Nécessite 3,3 V
  • Programmation un peu plus complexe

En résumé, le ESP32 est parfait pour les projets modernes nécessitant connectivité et puissance.

nRF24L01+PA (Long Range)

Prix : 6 000 FCFA

Module nRF24L01+PA (Amplifié)

Le nRF24L01+PA est un module de communication sans fil longue portée (2.4 GHz), idéal pour les projets de télécommande, robotique et drones.

Caractéristiques principales :

  • Fréquence : 2.4 GHz ISM
  • Portée : jusqu’à 1 km avec antenne
  • Débit : 250 kbps à 2 Mbps
  • Interfaces : SPI
  • Alimentation : 3.3 V
  • Amplificateur PA + antenne externe

Avantages :

  • Longue portée
  • Faible consommation
  • Excellente pour la communication Arduino/STM32/ESP32

Limitations :

  • Nécessite 3.3 V stable
  • Portée dépend de l’environnement

Carte Arduino Nano

Prix : 7 000 FCFA

Carte Arduino Nano

L’Arduino Nano est une carte microcontrôleur compacte et économique, parfaite pour les projets embarqués et l’apprentissage de l’électronique.

Caractéristiques principales :

  • Microcontrôleur : ATmega328P
  • Fréquence : 16 MHz
  • Mémoire : 32 Ko Flash, 2 Ko SRAM
  • Nombre de GPIO : 22 (14 numériques + 8 analogiques)
  • Interfaces : UART, SPI, I2C, PWM
  • Tension : 5 V (USB) / 7-12 V (Vin)

Avantages :

  • Taille compacte
  • Facile à programmer via Arduino IDE
  • Compatible avec de nombreux capteurs et modules

Limitations :

  • Moins puissant que l’ESP32
  • Pas de WiFi/Bluetooth intégré

Module L298N (Pont en H)

Prix : 5 500 FCFA

Module L298N (Pont en H)

Le L298N est un pilote de moteur double basé sur un pont en H, idéal pour contrôler moteurs DC et moteurs pas-à-pas.

Caractéristiques principales :

  • Contrôle jusqu’à 2 moteurs DC ou 1 pas-à-pas
  • Tension d’alimentation : 5 à 35 V
  • Courant max : 2 A par canal
  • Entrées compatibles TTL/CMOS
  • Bornes à vis pour moteurs et alimentation

Avantages :

  • Permet inversion de sens des moteurs
  • Supporte PWM pour la vitesse
  • Simple à utiliser avec Arduino/ESP32

Limitations :

  • Moins efficace que les pilotes modernes (ex. L298N chauffe)
  • Pas adapté aux moteurs très puissants
